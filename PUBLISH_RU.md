# Публикация Jospar v3

Постоянный адрес: https://jospar-fcaa0-v3.web.app/app.html
Демо: https://jospar-fcaa0-v3.web.app/demo.html
Маркер версии: https://jospar-fcaa0-v3.web.app/version.json

```powershell
npm run deploy:v3
```

Команда пересобирает SDK и публикует только hosting:v3. Она не публикует v1/v2, правила, Authentication или другие сервисы. Закреплённый Firebase CLI берётся из node_modules проекта, чтобы не зависеть от случайной latest-версии.

Google-провайдер включён отдельно по просьбе владельца. Для повторной настройки этого же проекта предусмотрен firebase.auth.json; он содержит только настройку Google-провайдера и служебный email поддержки, без секретных ключей. Регулярная публикация сайта не разворачивает этот файл.

Все версии используют проект jospar-fcaa0: аккаунты, база и квоты общие. Изменение правил Firestore затрагивает все версии и требует отдельного согласованного выпуска. Приватные ключи и .env не публикуются в public и не входят в архив.

Полная версия: https://jospar-fcaa0-v3.web.app/app.html — постоянный адрес без параметра версии. Выход из демо, вход в облако и приглашения команд ведут на этот адрес. HTML главной страницы отдаётся с Cache-Control: no-store, чтобы браузер не удерживал старую оболочку.
