# Jospar 3.2.1

Планировщик задач, проектов, привычек и целей с облачными аккаунтами, командным чатом и тремя темами оформления. Интерфейс на русском, казахском и английском языках.

## Открыть сайт

- Обычный режим: https://jospar-fcaa0-v3.web.app/app.html
- Демонстрация без регистрации: https://jospar-fcaa0-v3.web.app/demo.html

В обычном режиме доступны почта/пароль с подтверждением email и вход через Google. В демо используются пример данных и локальное сохранение: реальные письма, SMS, общие аккаунты и облачный чат не имитируются.

## Локальный запуск

Установите Node.js 22 или новее. Запустите `start-local.cmd`, затем откройте http://localhost:8089. Для примера данных откройте http://localhost:8089/demo.html или `start-demo.cmd`.

В PowerShell:

```powershell
cd "C:\Users\Фархат\Desktop\Jospar-firebase-spark-v3-coursework"
$env:PORT="8089"
npm start
```

После распаковки архива на другом компьютере сначала выполните `npm run setup`. Для установки зависимостей нужен интернет. После первого успешного открытия демо оно сохраняет статическую оболочку и работает при отключённом интернете в том же браузере. Обычный облачный режим требует связи с Firebase.

## Проверки

```powershell
npm test
npm run build
npm run test:browser
npm run test:firebase
```

Браузерный набор сам запускает временный сервер на свободном порту и закрывает его. Тесты облачного UI используют явно подменённый SDK; тесты Firestore — локальный demo-jospar. Реальные письма и SMS тесты не отправляют. Для эмуляторов нужна Java 21; Windows-обход длинного пути для временных сокетов включён только в процессе теста.

## Публикация только v3

```powershell
npm run deploy:v3
```

В команде используется закреплённый в lockfile Firebase CLI. Цель `hosting:v3` связана только с `jospar-fcaa0-v3`. Она не публикует v1/v2 и не заменяет общие правила Firestore. Аккаунты, база и квоты Firebase остаются общими с предыдущими версиями; для полной изоляции нужен отдельный Firebase-проект.

## Что подготовлено

- Ошибка сохранения и повтор доступны на телефоне и планшете.
- Мобильное меню закрывается при открытии формы.
- Google-вход, понятные ошибки popup и подтверждение email ссылкой.
- Демо с задачами, проектами, привычками и целью; сброс примера, экспорт/импорт.
- Автономная оболочка демо, отдельная от облачного режима.
- Отдельный канал и маркер версии 3.0.0.

## Границы бесплатной версии

Реальные SMS не включены: телефонный вход скрыт, платный тариф не подключается. Отправка push при закрытом сайте не объявлена готовой без доверенного работающего worker; открытый командный чат обновляется через Firestore. Вкладка уведомлений объясняет текущую доступность. Личные напоминания, список уведомлений, поиск и отчёты доступны в интерфейсе.

Для подготовки к показу читайте `COURSEWORK_RU.md`. Исторические `AUDIT_RU.md` и `CHANGES_V3_RU.md` описывают предыдущие этапы и не заменяют текущий README.

## Обновление 3.0.1

Исправлены сочетания клавиш при русской раскладке, сохранность формы при вызове поиска, быстрый ввод длинных/повторных тегов и неверного времени, а также сохранность следующего черновика чата при задержанной отправке. Ctrl+K работает внутри рабочего пространства после входа или в демо; при фокусе в адресной строке браузера сочетание обрабатывает браузер.

## Обновление 3.1.0: возврат и уведомления

Кнопка «Назад» доступна во всех основных разделах; она возвращает предыдущий экран и параметры календаря/поиска. В чате сначала открывает список команд, затем предыдущий раздел. На первом экране без истории кнопка неактивна.

Уведомления включены по умолчанию и работают внутри открытого сайта, без разрешений браузера. Задача должна иметь дату и время. Новые сообщения команды показываются также в других разделах; собственные сообщения и старая переписка карточек не вызывают. В видимом открытом чате сообщения обновляются сразу без повторной карточки.

Карточки плавно появляются и через 10 секунд плавно исчезают; крестик закрывает их раньше. Нажатие открывает задачу или чат. Одновременно показываются до трёх карточек, остальные ожидают очереди (до 50). Несохранённая форма защищена от случайной замены. Уведомления можно отключить в настройках. При закрытом сайте уведомлений нет; после сна вкладки напоминания за последние сутки проверяются при её возвращении.

Для показа: поставьте задаче время на следующую минуту, оставьте сайт открытым и дождитесь карточки. Для чата используйте два аккаунта и откройте у получателя другой раздел сайта.

## Оформление 3.2.0

Откройте меню профиля → «Настройки» → «Оформление». Доступны три темы: «После пар» (библиотека), «Рабочая тетрадь» (конспекты) и «Свой горизонт» (горы и озеро). Выбор применяется сразу, хранится в этом браузере и синхронизируется между вкладками. Светлый/тёмный режим выбирается отдельно, как прежде. Все три темы доступны в демо и после входа; данные задач не меняются.

Фоны и шрифты размещены в самой сборке. После первого полного открытия демо они доступны без интернета. Сведения о созданных через imagegen фонах и лицензиях шрифтов — docs/THEME_ASSETS.json и public/assets/fonts/*-OFL.txt.

На главном экране «Сегодня» кнопка «Назад» скрыта. В остальных разделах её левый край совпадает с краем содержимого. Возврат из командного чата сохранён.

Полная версия: https://jospar-fcaa0-v3.web.app/app.html — постоянный адрес без параметра версии. Выход из демо, вход в облако и приглашения команд ведут на этот адрес. HTML главной страницы отдаётся с Cache-Control: no-store, чтобы браузер не удерживал старую оболочку.
