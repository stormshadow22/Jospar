# Security — Jospar

Поддерживаемая версия: 3.3.x. Уведомить о проблеме приватно: m.shifu2009@gmail.com. Не публикуйте пароли, токены, чужие планы или рабочие данные в GitHub Issues.

Защита включает Firebase Authentication, подтверждение email, Firestore Security Rules, App Check для рабочей базы и серверные ограничения частоты записей. Правила доступа и ограничители проверяются в Firebase Emulator; UI-тесты с mock SDK не подтверждают реальную доставку почты или работу Google-входа.

При успешном облачном выходе локальные копии текущего аккаунта очищаются; пользователь получает уведомление, если браузер запретил удаление. Firebase-вход и App Check могут хранить служебные данные браузера. Деморежим намеренно хранит данные локально и не является защищённым облачным аккаунтом.

Ограничения: нет гарантии абсолютной защиты от злоупотреблений; App Check не заменяет вход и правила. История команд может сохраняться после удаления аккаунта, требуется административная обработка отдельных запросов удаления. Нужны регулярные обновления, наблюдение за бесплатными квотами и проверка восстановления резервных копий. Веб-конфигурация и reCAPTCHA site key являются публичными идентификаторами, сервисные ключи и App Check debug tokens публиковать нельзя.
