# Как публикуется Jospar

Основной репозиторий — https://github.com/stormshadow22/Jospar, стабильный код в main. Сайт работает отдельно на Firebase Hosting: https://jospar-fcaa0-v3.web.app/app.html. Исходники, документация и темы хранятся в Git; реальные аккаунты, планы и сообщения — в Firebase, а не в репозитории.

Рабочие версии отмечаются тегами. Перед отправкой: npm ci, npm ci --prefix server, npm run build, npm test, npm run test:browser, npm run test:firebase, npm audit и npm audit --prefix server. Не заменяйте номер версии поиском по всему lock-файлу: меняются только корневые поля package.json и lock.packages[""].version, остальное обновляет npm.

В публичный репозиторий не отправляются .env, сервисные ключи, App Check debug tokens, резервные копии реальных пользователей, node_modules и логи. Публичная веб-конфигурация Firebase и reCAPTCHA site key являются идентификаторами клиента, а не приватными ключами. Workflow использует только read-доступ и не публикует сайт автоматически.

Тексты сторонних лицензий сохраняются. Права на собственный код и работы соавторов не передаются автоматически при выборе публичного репозитория; разрешение на повторное использование определяется авторами отдельно.
